# lct-hack — учебный симулятор занятия для системы 112

Голосовой ИИ-тренажёр для подготовки операторов 112 и диспетчеров ДДС: звонящий играет происшествие и не выдаёт данные сам, курсант принимает вызов и заполняет карточку КИО, система оценивает по ГОСТ Р 22.7.03-2021 и собирает разбор для всей группы.

## Подъём

```
make models     модели: эмбеддинги, распознавание, VAD (синтез — вручную, скрипт подскажет)
make demo       стенд целиком: база, сценарии, бэкенд с голосом, фронт
```

Дальше открыть пульт преподавателя — `http://localhost:5173/instructor`. Он печатает ссылки на АРМ курсанта, внешний монитор и АРМ ДДС: их открывают на других машинах класса.

Без голоса, только логика и интерфейсы:

```
make dev        docker compose: postgres + backend + frontend
make lesson     запустить занятие и получить ссылки на экраны
```

## Что уже работает

| | |
|---|---|
| Голосовой контур | оператор говорит → распознавание → слот-автомат → ответ звонящего → синтез. Перебивание 88 мс, ход 1.2–1.4 с ([замеры](docs/LATENCY.md)) |
| Звонящий | не выдаёт данные сам, злится на повторы. Говорит своими словами на LLM, офлайн — по предгенерированной таблице |
| АРМ курсанта | приём вызова, карточка КИО по нормативу, таймеры ГОСТ, подсказки по запросу, самооценка |
| Пульт преподавателя | выбор сценария и режима, наблюдение, пометки к репликам, директивы: паника, агрессия, обрыв связи |
| Внешний монитор | ход занятия крупно, после оценки — разбор на весь экран |
| АРМ ДДС | снимок карточки, подтверждение за 30 с по нормативу, возврат на уточнение — сорванный выезд с причиной |
| Оценка | детерминированно по ГОСТ, каждая метрика фактом против норматива, таксономия E1–E6, радар компетенций |
| Разбор и профиль | эталонные вопросы по пропущенному, расхождение самооценки, дельта попыток |

Чего пока нет: судья на LLM, генератор сценариев, аналитика группы, классификатор ЕКП и статусы реагирования на АРМ ДДС. Состояние карточек — [tasks/README.md](tasks/README.md).

## Команды

```
make test       тесты бэкенда            make typecheck  проверка фронта
make test-voice голосовой контур на моделях   make latency    замер задержки по этапам
make seed       сценарии в БД            make migrate    миграции
make repl       диалог со звонящим без голоса и LLM
make back       бэкенд нативно, с голосом (сначала docker compose stop backend)
```
