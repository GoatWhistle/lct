# lct-hack — локальный учебный тренажёр 112 и ДДС

Тренажёр для подготовки операторов 112 и диспетчеров ДДС. Основной путь демонстрации задачи № 9: преподаватель выдаёт **готовую карточку** ДДС, курсант принимает её, назначает бригаду, связывается со старшим группы в учебной имитации телефона, фиксирует доклады и статусы, получает оценку. Есть также отдельная текстовая вводная для оператора 112 и прежний голосовой вызов. [Рабочая спецификация](docs/spec/TZ.md) отделяет требования заказчика от учебных допущений реализации.

## Подъём

```
make models     модели: эмбеддинги, распознавание, VAD (синтез — вручную, скрипт подскажет)
make demo       стенд целиком: база, сценарии, бэкенд с голосом, фронт
```

Дальше открыть пульт преподавателя — `http://localhost:5173/instructor`, выбрать упражнение «Готовая карточка ДДС» и открыть выданную ссылку на АРМ ДДС. Для режима 112 используется ссылка на АРМ курсанта. При первом запуске локальные модели нужно заранее скачать в контур стенда; `make demo` не является доказательством холодного запуска без сети.

Локальный стенд без голоса (карточки 112 и ДДС):

```
make dev           первоначальная сборка образов и запуск
make users-docker  один раз создать учётные записи внутри контейнера
make offline       последующий запуск без pull и build, из локальных образов
```

Для переноса на машину без сети нужны заранее собранные образы и репозиторий: [пошаговая инструкция](docs/arch/OFFLINE.md). `docker-compose.yml` выполняет миграции и загружает сценарии при запуске. Наличие кода не заменяет живую проверку стенда на целевой машине.

## Что уже работает

| | |
|---|---|
| Голосовой контур | оператор говорит → распознавание → слот-автомат → ответ звонящего → синтез. Перебивание 88 мс, ход 1.2–1.4 с ([замеры](docs/LATENCY.md)) |
| Звонящий | в режиме 112 ведёт диалог; офлайн — по предгенерированной таблице реплик, облачный LLM не обязателен |
| АРМ курсанта | текстовая вводная и КИО без голоса либо приём голосового вызова, таймеры, подсказки и самооценка в режиме звонка |
| Пульт преподавателя | выбор упражнения, курсанта и сценария, локальный редактор черновика с проверкой и утверждением, наблюдение и директивы для голосового режима |
| Внешний монитор | ход занятия крупно, после оценки — разбор на весь экран |
| АРМ ДДС | реестр готовых карточек, решение за 30 с, статусы реагирования, ручной выбор бригады и учебная имитация исходящего звонка |
| АРМ администратора | учётные записи и роли, состояние стенда, журнал действий, резервные копии |
| Оценка | проверка действий по карточке и ДДС; принятые командой веса и нормы показаны отдельно от требований заказчика |
| Разбор и профиль | эталонные вопросы по пропущенному, расхождение самооценки, дельта попыток, скачивание отчёта в CSV/PDF |

Классификатор ЕКП и автомат статусов ДДС уже есть. **Локального SIP-сервера нет**: телефон ДДС — учебная имитация, не выполнение формального требования SIP. Нет также подтверждённых нагрузочных показателей, полноценного нейрогенератора сценариев и групповой аналитики. Текущие пробелы — в [GAP.md](docs/spec/GAP.md), задачи разработки — в [tasks/README.md](tasks/README.md).

## Команды

```
make test       тесты бэкенда            make typecheck  проверка фронта
make test-voice голосовой контур на моделях   make latency    замер задержки по этапам
make seed       сценарии в БД            make migrate    миграции
make users      учётные записи ролей     make ekp        классификатор происшествий
make backup     резервная копия базы     make lesson     занятие и ссылки на экраны
make repl       диалог со звонящим без голоса и LLM
make back       бэкенд нативно, с голосом (сначала docker compose stop backend)
```
