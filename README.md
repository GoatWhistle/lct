# lct-hack — учебный симулятор занятия для системы 112

Голосовой ИИ-тренажёр для подготовки операторов 112 и диспетчеров ДДС: звонящий играет происшествие и не выдаёт данные сам, курсант принимает вызов и заполняет карточку КИО, система оценивает по ГОСТ Р 22.7.03-2021 и собирает разбор для всей группы.

## Документация

```
docs/
├── product/                  # ЧТО строим и как это обучает
│   ├── OVERVIEW.md           #   продукт, интерфейсы, приоритеты, Definition of Done
│   ├── CALL-SIM.md           #   симуляция звонка: персоны, слоты, дуга, память, фон
│   ├── METHODOLOGY.md        #   чек-листы опроса, таксономия ошибок, компетенции, занятие
│   ├── DEBRIEF.md            #   разбор: эталон, самооценка, пометки, оценка
│   └── MODES.md              #   режимы, подсказки, повтор сценария, профиль курсанта
├── spec/                     # Нормативная база
│   ├── TZ.md                 #   ТЗ заказчика
│   ├── NORMATIVES.md         #   ГОСТ Р 22.7.03-2021, КИО, классификаторы ДДС
│   └── SCENARIO-FORMAT.md    #   YAML-схема сценария
```

Начинать с [docs/product/OVERVIEW.md](docs/product/OVERVIEW.md).

## Подъём

```
make dev        # docker-compose: postgres + backend + frontend
make types      # domain/events.py → frontend/src/shared/types/generated.ts
make test       # тесты контракта
```

Если `npm install` под WSL2 висит без загрузки процессора — дело в параллельных сокетах,
ограничение лежит в [frontend/.npmrc](frontend/.npmrc).

Работает сейчас: каркас бэкенда (`/api/health`), домен и контракт в `backend/app/domain/`,
генерация типов фронта, заглушки четырёх экранов. `make models`, `make seed`, `make repl`,
`make pregen`, `make demo` пока падают и называют карточку, которая их закрывает.

## Работа над задачами

```
tasks/<id>.md        карточка: зачем, что сделать, готово когда
PROMPT-<id>.md       задание агенту на исполнительный гайд
TASK-<id>.md         сам гайд: файл → что сделать → готовый код → как проверить
```

Порядок и зависимости — [tasks/README.md](tasks/README.md). Сначала `lct-01` и `lct-02`:
первая разблокирует фронт типами, вторая решает, RNNT или CTC.
