# lct-hack — учебный симулятор занятия для системы 112

Голосовой ИИ-тренажёр для подготовки операторов 112 и диспетчеров ДДС. Звонящий играет
происшествие и **не выдаёт данные сам**, курсант принимает вызов и заполняет карточку КИО,
система оценивает по ГОСТ Р 22.7.03-2021, разбор идёт на всю группу.

Хакатон ЛЦТ 2026, кейс «Город №9». Разработка 15.09–29.09.2026, сдача 29.09.

## Где что лежит

```
docs/product/   что строим и как это обучает — начинать с OVERVIEW.md
docs/spec/      ТЗ заказчика, нормативы, датасет (DATASET.md), формат сценария
docs/arch/      CONTRACT.md (шов фронт/бэк), BACKEND.md, FRONTEND.md, STACK.md
tasks/          карточки задач + порядок работ в tasks/README.md
backend/app/domain/   контракт в коде: КИО, события, таймеры, таксономия
scenarios/      YAML-библиотека сценариев
```

## Как ведётся работа

```
tasks/<id>.md     карточка: зачем, что сделать, готово когда
PROMPT-<id>.md    задание агенту на гайд (скилл task-guide-prompt)
TASK-<id>.md      исполнительный гайд: файл → что сделать → готовый код → как проверить
```

Гайд верит **коду, а не карточке**: карточки писались до реализации, расхождения выносятся
отдельным разделом. Порядок задач и зависимости — [tasks/README.md](tasks/README.md).

Ветки короткие: `feat/<что>`, PR смотрит владелец соседней зоны, если задет контракт.

## Команды

```
make dev        docker compose: postgres + backend + frontend (без голоса)
make back       бэкенд нативно, с голосовым контуром (сначала docker compose stop backend)
make types      domain/events.py → frontend/src/shared/types/generated.ts
make test       тесты бэкенда
make test-voice голосовой контур на настоящих моделях: задержка и перебивание
make typecheck  tsc --noEmit на фронте
make models     эмбеддинги, GigaAM, Silero VAD; Silero TTS — вручную, скрипт подскажет
make latency    замер моделей речи по этапам
make lesson     запустить занятие и напечатать ссылки на экраны
make seed       сценарии в БД
make repl       текстовый диалог со звонящим, без голоса и LLM
make migrate    накатить миграции
```

`make demo` поднимает стенд целиком: база, сценарии, бэкенд с голосом, фронт.
`pregen` строит офлайн-таблицу реплик; сеть нужна только ему.
**Makefile не должен врать:** цель либо работает, либо честно падает с именем карточки.

## Решения, которые не переоткрываются

- **Источник истины контракта — Pydantic в `backend/app/domain/`.** TypeScript генерируется
  через `make types`, руками `generated.ts` не правится. Правка события без регенерации
  ловится тестом `test_generated_types_match_models`.
- **Один воркер uvicorn.** Состояние живой сессии и реестр наблюдателей — в памяти процесса.
- **Таймеры ГОСТ останавливаются событиями, а не таймаутами** — иначе метрику нельзя предъявить.
- **Оценка гибридная:** 60% детерминированно по ГОСТ, 40% LLM-судья с `temperature=0`
  и только на мягкие критерии (E4). Ни одной отметки без кода и обоснования.
- **Подсказки без LLM:** следующий неотработанный пункт чек-листа по слот-автомату.
- **Фронт не хранит состояние сессии как истину** — при расхождении выигрывает сервер.
- **На сокете `observe` нет обработчиков входящих сообщений;** преподаватель пишет
  через отдельный `control`, и там нет ни одной команды, меняющей карточку курсанта.
- **`GET /api/scenarios/{id}` не отдаёт `facts` и `ground_truth`** — курсант откроет DevTools.
- **Все `at` — серверное UTC.**

## Порядок приоритетов

Учебное ядро не режется никогда: подсказки, эталон, самооценка, таксономия, режимы,
пульт директив. Порядок отсечения при нехватке времени: агрегат группы → генератор
сценариев → цепочка ДДС → ЭРА-ГЛОНАСС и программы занятий
([OVERVIEW.md](docs/product/OVERVIEW.md#приоритеты)).

## Язык и стиль

Документация, карточки, комментарии и коммиты — по-русски. Комментарий объясняет **почему**,
а не пересказывает код. Оформление интерфейсов строгое и казённое: системный шрифт,
плотная сетка, таблицы вместо карточек; цвет несёт смысл только в трёх состояниях
норматива (`ok` / `warn` / `violated`).
