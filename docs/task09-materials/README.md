## Важные уточнения из чата (выжимка)

- Роли в тренажёре: один интерфейс, одна учётка, две мини-роли (#624, #628, #635):
  - **Оператор 112 (A)**: заполняет карточку по вводной (текст от ИИ или, если получится, голос), выбирает службы; проверяется соответствие сказанного и заполненного (#642).
  - **Диспетчер ДДС (B)**: принимает/отклоняет готовую карточку, проверяет корректность (ошибки «оператора 112», например в адресе), звонит руководителям служб (C) через симулятор IP-телефонии, ведёт статусы (#638).
- Голос живого заявителя имитировать не обязательно; для MVP достаточно имитации звонков в базе, реальная виртуальная телефония — плюс (#570, #576).
- Для телефонии фокус — взаимодействие B ↔ C (#638).
- Коды «Сценарий реагирования» в классификаторе — технические номера разработчиков 112; под каждый сценарий своя опросная карта для оператора 112; для ДДС сценариев нет (#683).
- Для 112 службы подтягиваются автоматически по опросной карте (можно добавить вручную); для ДДС бригады выбираются вручную; ДДС использует IP-телефон; статусы меняет только оператор ДДС; «универсальный алгоритм для всех» служб (#684).
- Дизайн: карточка и реестр обращений должны быть на 100% похожи на оригинал (цвета и компоновка), остальное — не критично (#679, #680).
- «Мобильное» в ТЗ участники трактуют как адаптивный интерфейс.
- SourceCraft не обязателен (#257). GPU-ВМ по промокоду Yandex Cloud не поддерживаются (только DataSphere) (#452).
- Повторной Q&A-сессии не планируется (#674). При противоречиях — ориентир на ТЗ как первоисточник (#625).
- Службы подтягиваются по району обслуживания и подчинённости (пример: пожар в школе в Щукино → 01, 02, 03, ДДС Департамента образования, ДДС управы Щукино, ДДС СЗАО) (#690).
- ДДС ↔ бригада: только телефон; решение о выезде — диспетчер (если есть полномочия) или руководство; статусы ДДС получает по телефону/радио: старший группы звонит с докладом ИЛИ диспетчер сам периодически звонит старшему — оба варианта (#691).
- Открытые вопросы без ответа: #692 (как добавляются службы в карточке ДДС), #689 (кто второй абонент IP-телефона ДДС), #650 (доступ ДДС к аудио звонка), #659 (записи учебных звонков).
