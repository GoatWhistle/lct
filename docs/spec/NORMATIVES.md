# Нормативная база — ГОСТ Р 22.7.03-2021, ПП РФ № 2071, КИО, классификаторы

Единственный источник требований к АРМ и оценке. Интерфейс и метрики строятся по нормативу, а не по догадкам: доступ к боевому ПО системы-112 желателен, но не критичен.

## Временные нормативы приёма вызова

Действуют в детерминированном слое оценки ([product/DEBRIEF.md](../product/DEBRIEF.md)) и в таймерах интерфейсов.

| Операция | Норматив |
|---|---|
| Ответ на звонок | ≤ 8 сек |
| **Опрос / идентификация ситуации** | **≤ 75 сек** |
| Оповещение ДДС | ≤ 60 сек |
| Подтверждение получения карточки | ≤ 4 сек |
| Проверка зоны ответственности | ≤ 30 сек |
| Обратный дозвон при обрыве | ≤ 10 сек набора, 3 попытки |
| Снятие с контроля | ≤ 5 мин |

Каждая метрика оценки отображается как «факт против норматива со ссылкой»: «время опроса 94 с при нормативе 75 с (ГОСТ Р 22.7.03-2021)».

## Карточка информационного обмена (КИО)

Структура задаёт поля формы АРМ оператора ([arch/FRONTEND.md](../arch/FRONTEND.md)):

- **Служебное:** дата, время, статус реагирования
- **Звонящий:** номер (автоопределение), ФИО, контактный телефон, язык общения
- **Место:** ОКАТО, адрес, улица, дом, подъезд, этаж, координаты
- **Происшествие:** тип по классификатору, описание, число пострадавших, признак ЧС, угроза жизни, необходимость эвакуации
- **ДДС:** время выдачи приказа на выезд, время прибытия

## Алгоритм приёма вызова

Последовательность, отображаемая как этапы звонка (используется в эмоциональной дуге сценария и в разборе):

```
звонок → регистрация → идентификация номера → приоритизация
      → первичный опрос → заполнение КИО → передача в ДДС → контроль реагирования
```

## Уровни сложности сценариев

| Уровень | Сценарий |
|---|---|
| L1 | Простой пожар, вменяемый заявитель, адрес назван сразу |
| L2 | Медицинский вызов, паникующий заявитель |
| L3 | Обрыв связи, требуется обратный дозвон (3 попытки по 10 сек) |

Спец-типы звонящих (скрывающий информацию, ребёнок, иностранец) и ЭРА-ГЛОНАСС описаны в [product/CALL-SIM.md](../product/CALL-SIM.md); они комбинируются с уровнями.
