# Бюджет задержки — замеры

Заполняется карточкой [lct-02](../tasks/lct-02-latency-baseline.md). Цифры, а не «примерно
работает»: от них зависит решение RNNT/CTC и вся ветка деградации ([STACK.md](arch/STACK.md)).

Замер делается **на той машине, которая поедет на занятие**.

## Стенд

| | |
|---|---|
| Машина | _модель, CPU, RAM_ |
| ОС | _и WSL2, если Windows_ |
| Запуск моделей | _в контейнере / нативно_ |
| Дата замера | _дд.мм.2026_ |

## Этапы

Целевой суммарный бюджет — **0.8–1.5 с** от конца реплики оператора до первого звука ответа.

| **Итого** | **0.8–1.5 с** | | | |
