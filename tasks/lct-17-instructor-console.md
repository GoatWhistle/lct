# Пульт преподавателя

## Зачем

Это интерфейс для действующего преподавателя, и он оценит его по четырём вещам: задать
сценарий и не вмешиваться, видеть работу обучаемого вживую, получить готовый разбор,
показать группе на экране.

## Что сделать

- Слева выбор сценария: уровень, тема, режим. Кнопка запуска — крупная, одна.
- По центру живая сессия: транскрипт, карточка, таймеры, счётчик подсказок.
- Справа история группы.
- Пометки: клик по реплике → поле комментария → `instructor_note.add`, значок у реплики
  виден всем, кому виден транскрипт.
- Наблюдение через `observe`, запись через `control` — **разные сокеты**.

## Готово когда

- [ ] Преподаватель запускает занятие в выбранном режиме и не вмешивается в разговор
- [ ] Транскрипт, карточка и таймеры обновляются вживую
- [ ] Пометка видна курсанту в его истории

## Состояние

Пульт собран: выбор сценария, режима и курсанта слева, живое занятие по центру
(таймер опроса, транскрипт, нормативы, карточка read-only, счётчик подсказок),
история справа, разбор внизу после оценки. Ссылки на АРМ курсанта и внешний
монитор печатаются тут же — открываются со второй машины.

Пометки: клик по реплике → поле комментария → `instructor_note.add`; пометка
видна всем, кому виден транскрипт, и попадает в отчёт.

**Разделение прав соблюдено:** пульт смотрит через `observe`, пишет через
`control`, карточка курсанта у него только для чтения.

**Чинилось по ходу:** запуск занятия шёл из эффекта и мог уйти повторно при
перерисовке, а открытая из истории ссылка на идущее занятие запустила бы его
заново и сбросила. Теперь запускается только занятие, созданное кнопкой.

**Не проверено:** отрисовка и работа в браузере — нужен человек. Пульт директив
(«связь обрывается», «паника нарастает») — карточка lct-22.
