# Звук в обе стороны

## Зачем

Вертикальный срез по звуку замыкается здесь: слышно звонящего, видно свою расшифровку,
оператор может перебить.

## Что сделать

- `shared/audio/playback.ts` — очередь `AudioBufferSourceNode`, **не `<audio>`**:
  barge-in требует оборвать воспроизведение мгновенно и выбросить очередь.
- Планирование чанков по `AudioContext.currentTime`, ссылки на активные ноды,
  сброс по `tts.cancel`.
- `shared/audio/levels.ts` — локальный энергетический гейт: фронт даёт скорость,
  сервер по VAD подтверждает.
- `shared/audio/ambience.ts` — `bg.start`/`bg.stop`, зацикленный файл из сборки.

## Готово когда

- [ ] Кнопка «Ответить» → слышно звонящего, видно расшифровку своей речи
- [ ] Речь оператора гасит звук звонящего под 150 мс
- [ ] Фон звучит тише голоса и не мешает распознаванию

## Состояние

Написано и подключено к экрану курсанта: очередь воспроизведения
(`shared/audio/playback.ts`), энергетический гейт перебивания (`levels.ts`),
аудио-фон (`ambience.ts`), приём бинарных кадров в WS-клиенте, экран
`/trainee` с приёмом вызова, лентой разговора и кнопкой подсказки.

**Проверено без браузера** (логика вынесена из WebAudio и прогнана в Node):
чанки планируются встык без щелей и наложений, перебивание останавливает все
запланированные чанки и обнуляет очередь, новая реплика планируется от текущего
момента; гейт не срабатывает на шуме, ловит начало речи ровно один раз на втором
кадре (40 мс) и ловит следующее начало после паузы.

**Требует человека с браузером и гарнитурой** — три пункта приёмки выше:

    make back            бэкенд нативно, с голосом (сначала docker compose stop backend)
    make front           фронт
    make lesson          ссылка на /trainee?session=…
    открыть в Chrome     «Ответить» → должно быть слышно «Алло! Помогите!»
                         спросить адрес голосом → звонящий называет адрес
                         заговорить, пока он говорит → звук должен оборваться мгновенно

**Не сделано:** записей фона нет — `frontend/public/ambience/README.md` описывает,
что туда класть; без файла звонок идёт без фона и не падает.
