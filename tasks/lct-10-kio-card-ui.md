# Карточка КИО

## Зачем

Самый крупный компонент проекта и то, по чему методист сразу поймёт, читали ли мы норматив.

## Что сделать

- Пять групп полей по нормативу плюс уточняющие по выбранной службе.
- `kio.patch` с дебаунсом 300 мс, шлётся **только дельта**.
- **Фронт не хранит карточку как истину:** сервер шлёт `kio.patch` с `source: "auto"`,
  при расхождении выигрывает сервер. Локальное состояние — оптимистичное отображение
  своего ввода до подтверждения.
- Режим read-only с первого дня: тот же компонент рисуется на мониторе, пульте и АРМ ДДС.

## Готово когда

- [ ] Все группы полей норматива присутствуют, поля валидируются
- [ ] Автозаполнение из речи и ручной ввод не дерутся за одно поле
- [ ] Компонент рисуется read-only без правок пропсов
