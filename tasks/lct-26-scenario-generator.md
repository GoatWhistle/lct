# Генерация сценариев

## Зачем

В ТЗ это сценарий «Настройка учебной среды», а не пожелание: преподаватель выбирает
категорию событий, нейросеть генерирует происшествия **и эталонные ответы**, преподаватель
подтверждает их полностью или частично, смотрит предпросмотр с подсветкой правильных
ответов, а при неверной генерации пишет комментарий в свободное поле — и система
переделывает по нему.

Ключ LLM работает, так что препятствий больше нет.

## Что сделать

- `scenarios/generator.py`: описание словами → черновик сценария по схеме, один
  структурированный вызов с целевой Pydantic-моделью.
- Эталон не генерируется, а **выводится из фактов кодом**: иначе модель напишет в фактах
  «Ленина, 14», а в эталоне «Ленина, 4».
- Цикл валидации с регенерацией: схема, непротиворечивость, полнота — до трёх попыток.
- Экран: поле описания, предпросмотр черновика с подсветкой, поле комментария,
  кнопка публикации. Публикует только преподаватель.

## Готово когда

- [ ] Из описания «пожар в многоквартирном доме, паникующая женщина» выходит валидный сценарий
- [ ] Комментарий преподавателя меняет черновик так, как он просил
- [ ] Черновик не попадает в библиотеку без явной публикации
