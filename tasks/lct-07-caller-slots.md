# Звонящий, который не выдаёт данные сам

## Зачем

Ключевая механика, отличающая тренажёр от чат-бота. Тот же автомат детерминированно
отвечает на вопрос «спросил ли оператор про этаж» — без него оценка полноты опроса
превращается в догадку LLM.

## Что сделать

- `dialog/slots.py` — автомат фактов: `question` через эмбеддинги (`multilingual-e5-small`),
  `approach` через LLM с бинарным решением. В контекст подмешиваются **только раскрытые** факты.
- Повторный вопрос по раскрытому факту помечается и уходит в персону как раздражение.
- `dialog/persona.py` — профили, эмоциональная дуга по этапам, состояние.
- `dialog/llm.py` — провайдеро-независимый клиент, стриминг, кэш по хешу контекста в Postgres.
- `dialog/prompts/` — промпты файлами, не в коде.
- `make repl` — текстовый диалог со звонящим без голоса. Работает до готовности lct-06.

## Готово когда

- [ ] В `make repl` адрес не выдаётся, пока его не спросили
- [ ] «На каком этаже?», «этаж какой?», «а этаж» раскрывают один и тот же факт
- [ ] Повторный вопрос вызывает раздражение, а не второй вежливый ответ
- [ ] Скрытый факт не раскрывается прямым вопросом и раскрывается после эмпатии
