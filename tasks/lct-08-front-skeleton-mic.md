# Каркас и микрофон

## Зачем

Единственная задача, которая может подорваться на неожиданностях браузера, — поэтому
она первая, а не последняя.

## Что сделать

- `shared/api/ws.ts` — сокет с переподключением и типизированными событиями из `generated.ts`.
- `shared/api/http.ts` — клиент и хуки TanStack Query.
- `shared/audio/capture.ts` + `worklet.ts` — `getUserMedia` → AudioWorklet, ресемплинг в 16 кГц,
  кадры по 20 мс. **Ресемплинг делает фронт, не сервер.**
- Роутинг четырёх экранов, `session_id` из URL, а не из сообщения.

## Готово когда

- [ ] Кадры PCM16 16 кГц долетают до бэкенда, и он их видит в логе
- [ ] Обрыв WS восстанавливается без перезагрузки страницы
- [ ] `npm run build` проходит с актуальным `generated.ts`
