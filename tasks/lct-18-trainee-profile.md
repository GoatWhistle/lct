# Профиль и прогресс

## Зачем

«Контроль подготовленности» из ТЗ — не таблица оценок, а инструмент планирования
подготовки. Работа над ошибками становится измеримым циклом: разбор → повтор → дельта.

## Что сделать

- `GET /api/trainees/{id}/profile` и `GET /api/sessions/{id}/attempts`.
- SVG-радар шести компетенций, при нескольких попытках — динамика.
- История сессий с фильтром по режиму и периоду; самостоятельные помечены отдельно.
- **Дельта попыток по сценарию:** время опроса, полнота чек-листа, коды ошибок.
- Сильные и слабые стороны собираются из радара автоматически.

## Готово когда

- [ ] Две попытки по одному сценарию видны с дельтой метрик
- [ ] Контрольные попытки отделены от тренировочных
- [ ] Пометки преподавателя из всех сессий собраны в профиле
