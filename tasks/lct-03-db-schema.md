# Схема данных и первая миграция

## Зачем

Профиль курсанта, дельта попыток и аналитика группы строятся по журналу, а не по памяти
процесса. Всё, что не записано в сессии, для оценки не существует.

## Что сделать

- `db/models.py`: курсанты, **группы**, сессии, реплики, отметки, самооценки, подсказки,
  попытки, заметки преподавателя, оценки, кэш LLM по хешу контекста.
- Alembic, первая миграция. **Таблица `groups` и связь `trainee → group` — сразу, даже пустыми.**
- `repo.py`: запись реплик и отметок, чтение истории с фильтром по курсанту, группе, режиму, датам.
- `POST /api/sessions` принимает `group_id` и `mode` с первого дня.

## Готово когда

- [x] `make dev` поднимает Postgres, миграция накатывается на чистую базу
- [x] Сессия создаётся, реплики пишутся, история читается с фильтрами
- [x] Повторный накат миграций не падает

## Не входит

Оценка и отчёты — они читают эти таблицы, но пишутся в lct-12 и lct-16.
