# Системная картина группы

## Зачем

ТЗ: преподаватель получает «аналитические рекомендации от системы (инсайты ИИ по типичным
ошибкам группы)». Критерии экспертизы отдельно упоминают наглядность диаграмм
и «рекомендации сервиса». Данные для этого уже пишутся в журнал каждым занятием.

## Что сделать

- `GET /api/groups/{id}/analytics`: доля курсантов по каждому типу ошибки за период,
  чистым SQL по накопленным сессиям.
- Экран: таблица системных пробелов с процентами («70% не уточняют этаж») и диаграмма.
- Формулировка вывода: одна фраза, что разбирать на следующем занятии.

## Готово когда

- [ ] Каждую цифру можно проверить руками по журналу сессий
- [ ] Преподаватель видит тему следующего занятия, а не просто таблицу
- [ ] Диаграмма читается с проектора
