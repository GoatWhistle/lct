# Судья на мягкие критерии

## Зачем

40% веса и только E4: тон, эмпатия, управление диалогом, работа с паникующим, лишние вопросы.
Всё остальное считает код — судье не отдаётся ничего, что можно посчитать детерминированно.

## Что сделать

- `scoring/judge.py` — **`temperature=0`**, не стриминг, структурированный JSON с обоснованием
  по каждому пункту, усреднение 2–3 прогонов.
- `scoring/rubric.py` — критерии с примерами.
- Потолок влияния: 40% итога, не больше.

## Готово когда

- [ ] Один транскрипт, прогнанный пять раз, даёт совпадающие вердикты
- [ ] По каждому пункту есть текстовое обоснование, пригодное для показа курсанту
- [ ] При недоступности сети оценка считается без судьи и это видно в отчёте

## Датасет, 19.09.2026

Во втором режиме занятия у судьи появляется работа, которой не было в этой карточке:
**полнота комментария к отказу** (D5 из [lct-33](lct-33-response-statuses.md)). Памятка
разбирает именно это — «не принята: не обслуживаем» без указания, куда передана
информация, считается нарушением, и формально это не проверить.

Критерий тот же по природе, что E4: мягкий, требует чтения текста, детерминированно
не считается. В рубрику его добавить примерами прямо из памятки — они там с разбором.
