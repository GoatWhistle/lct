# Задачи

Карточка описывает **замысел**: зачем, что сделать, готово когда. Она не гайд —
по ней нельзя писать код подряд, не думая. Гайд собирается отдельно:

```
tasks/<id>.md     карточка
PROMPT-<id>.md    задание агенту на гайд (скилл task-guide-prompt)
TASK-<id>.md      исполнительный гайд: файл → что сделать → готовый код → как проверить
```

Правило гайда: **верить коду, а не карточке**. Карточки писались до реализации,
расхождения выносятся в гайде отдельным разделом и возвращаются в карточку.

## Порядок

**День 1 — разблокировка.** `lct-01` и `lct-02` идут параллельно и не зависят ни от чего.
Первая разблокирует фронт типами, вторая решает RNNT или CTC. В тот же день закрываются
четыре вопроса из [STACK.md](../docs/arch/STACK.md#решения-которые-надо-закрыть-в-первый-день):
провайдер LLM, ONNX-экспорт Silero, Docker или нативный запуск, укладывается ли RNNT в бюджет.

**Дни 2–5 — параллельные треки.** Бэк-архитектор: `lct-05`. Бэк-2: `lct-03`, `lct-04`.
AI: `lct-07` (в `make repl`, голос не нужен). Фронт: `lct-08`. Лид: сценарии и чек-листы.

**Дни 5–8 — вертикальный срез.** `lct-06` + `lct-09`, `lct-10`, `lct-11`.
Веха: позвонили → поговорили голосом → заполнили карточку. Раньше этого ничего не полируем.

**Дни 8–11 — учебное ядро.** `lct-12`, `lct-13`, `lct-14`, `lct-15`, `lct-19`.

**Дни 11–13 — интерфейсы занятия.** `lct-16`, `lct-17`, `lct-18`, `lct-22`.

**Дни 13–15 — сдача.** `lct-20`, если успеваем; `lct-21` — прогоны, демо-режим, ролик.

## Порядок отсечения

Зафиксирован в [OVERVIEW.md](../docs/product/OVERVIEW.md#приоритеты) и не обсуждается на бегу:
сначала агрегат группы, затем генератор сценариев, затем цепочка ДДС (`lct-20`),
затем ЭРА-ГЛОНАСС и программы занятий.

**Не режется никогда:** подсказки (`lct-14`), эталон (`lct-19`), самооценка (`lct-15`),
таксономия (`lct-12`), режимы (`lct-14`), пульт директив (`lct-22`).

## Чего здесь нет

Should и Could из `OVERVIEW.md`, не попавшие в карточки: скрывающий информацию звонящий,
персоны «ребёнок» и «иностранец», генератор сценариев, агрегат ошибок группы, ЭРА-ГЛОНАСС,
программы занятий. Заводятся карточками, когда учебное ядро замкнётся.
