# Выгрузка отчётов

## Зачем

ТЗ называет форматы прямо: CSV для статистической отчётности, PDF для документов
и сертификатов. Экспорта у нас нет вовсе, а отчётность — то, ради чего преподаватель
пользуется системой после занятия.

## Что сделать

- `GET /api/sessions/{id}/report.pdf` — разбор одного занятия.
- `GET /api/groups/{id}/analytics.csv` — статистика группы за период.
- PDF собирается без тяжёлых зависимостей и без внешних сетей: контур локальный.

## Готово когда

- [ ] Файл открывается в Excel и в просмотрщике PDF без правки руками
- [ ] Кириллица не превращается в вопросительные знаки
- [ ] Выгрузка работает при выключенном интернете
